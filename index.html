¿Para qué sirve este portal?

El objetivo del proyecto es presentar una idea de aplicación web donde el usuario puede informarse, conocer servicios disponibles y enviar solicitudes sin necesidad de backend.

  • Explica la propuesta del servicio
  • Usa rutas relativas entre páginas
  • Integra etiquetas semánticas y formularios
  • Incluye tipografía, colores y estructura de contenido
