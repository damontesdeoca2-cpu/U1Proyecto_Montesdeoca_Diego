Acerca del proyecto

Este proyecto es un ejemplo práctico de sitio web multipágina para una idea de servicio ambiental aprobada en la Unidad 1.

Misión del sitio

Crear una experiencia clara para el usuario, donde se explique para qué sirve la plataforma y cómo navegar entre las páginas.

  • Mostrar servicios disponibles
  • Explicar la estructura del proyecto
  • Ayudar a generar consultas con un formulario

Detalles de diseño

Se utilizan etiquetas semánticas como header, main, section, article, aside y footer.

El proyecto usa enlaces relativos entre páginas y un formulario con método GET para enviar consultas sin backend.

Estructura de carpetas

  1. index.html - Página principal.
  2. about.html - Información del proyecto.
  3. services.html - Detalle de servicios.
  4. contact.html - Formulario de contacto.
  5. css/styles.css - Estilos globales.
  6. images/ - Imágenes e ilustraciones SVG.

Una página clara para mostrar el propósito del proyecto.
