Acerca de ChullaCine

ChullaCine es un sitio web de ejemplo que simula la página de un cine local, con cartelera, promociones y contacto para consultas.

Objetivo del proyecto

El objetivo es construir un sitio multipágina con una idea realista de cine, aplicando HTML semántico, rutas relativas, formularios y recursos de diseño.

  • Mostrar la propuesta de ChullaCine
  • Organizar contenido en páginas separadas
  • Usar un formulario GET para consultas

Elementos técnicos

Este proyecto utiliza header, nav, main, section, article y footer correctamente.

Los enlaces entre páginas son relativos y el formulario funciona con método GET para cumplir la unidad actual sin backend.

Estructura de carpetas

  1. index.html - Página de inicio con presentación y navegación.
  2. about.html - Explica el propósito del proyecto y la idea de cine.
  3. services.html - Presenta la cartelera y servicios relacionados.
  4. contact.html - Formulario de contacto y horarios de funciones.
  5. css/styles.css - Estilos del sitio con colores y tipografía.
  6. images/ - Ilustraciones SVG del cine y la cartelera.

Proyecto docente con estilo de cine y navegación clara.
