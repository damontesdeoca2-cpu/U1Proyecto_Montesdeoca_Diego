## Descripción general del proyecto

El proyecto consiste en un sitio web multipágina que presenta una idea de servicio ambiental.
La página está diseñada para explicar su propósito, mostrar servicios, incluir navegación y permitir el envío de una consulta mediante un formulario GET.

El objetivo es cumplir los criterios de la Unidad 1 con HTML, CSS, rutas relativas, tipografía, colores, etiquetas semánticas y un formulario básico.

## Estructura de carpetas

- `index.html` - Página principal con presentación general.
- `about.html` - Página de información sobre la propuesta y la estructura del proyecto.
- `services.html` - Página con los servicios y beneficios del portal.
- `contact.html` - Página con formulario de contacto y tabla de horarios.
- `css/styles.css` - Estilos globales para todo el sitio.
- `images/` - Imágenes SVG utilizadas como ilustraciones.
- `package.json` - Configuración del proyecto para generación de PDF.
- `.gitignore` - Archivos excluidos del control de versiones.

## Descripción de cada página

### Inicio (`index.html`)
- Presenta el servicio con un título principal y botones claros.
- Contiene un héroe con imagen ilustrativa, lista de características y una tabla de estructura.
- Navegación relativa hacia todas las secciones principales.

### Acerca (`about.html`)
- Explica la misión y la propuesta del proyecto.
- Incluye etiquetas semánticas como `article`, `aside` y `section`.
- Describe la estructura de carpetas y el uso de técnicas HTML/CSS.

### Servicios (`services.html`)
- Lista los paquetes disponibles con tarjetas descriptivas.
- Presenta iconografía visual y textos claros.
- Aplica listas, imágenes y texto semántico.

### Contacto (`contact.html`)
- Contiene un formulario de contacto con método `GET`.
- Incluye campos de nombre, email, asunto y mensaje.
- Añade una tabla de horarios con información de atención.
